# ESP32 BMS Lab

배터리 없이 USB 5V와 키트 부품으로 만든 ESP32 BMS의 3D 가상 실습실입니다.
한국어 · English · 日本語 · 中文을 지원합니다.

배포 주소: https://esp32-bms-lab3d.vercel.app

## 파일
- `index.html` : 화면 구조와 디자인
- `i18n.js` : 4개 언어 번역
- `lab.js` : 3D 회로, 가상 BMS 시뮬레이터, 조립 단계, 실제 보드 연결(Web Serial)
- `firmware/ESP32_BMS_TFT_v3.zip` : 코드 단계에서 내려받는 펌웨어
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` : 탭·홈 화면 아이콘
- `og.png` : 링크 공유 미리보기 이미지 (1200×630)

빌드 과정이 없는 정적 사이트입니다. 폴더 구조 그대로 올리면 됩니다.

## v5에서 바뀐 점
- 버튼에 포커스가 있을 때 Space를 누르면 부하가 같이 켜지던 버그 수정
- 겹친 카드에 가리지 않도록 3D 화면 중심과 거리를 자동 조정, 키 낮은 화면에서 카드 축소, 카드 숨기기 버튼
- 파비콘과 공유 미리보기 이미지 추가
- 추세 그래프가 처음부터 화면 폭을 채우도록 개선 (SIM/LIVE 표시)
- 시리얼 모니터 맨 위에 열 이름 줄, SOC 열 설명
- 점검 체크리스트 상태를 브라우저에 저장
- 뜨거운 물 실험에서 45°C 전에 위험이 뜨는 이유 설명
- **실제 보드 연결**: 데스크톱 Chrome·Edge에서 ESP32를 USB로 연결하면 펌웨어의 DATA 줄로 화면이 움직임. 부하·리셋 버튼은 on/off/reset 명령을 보냄
- **펌웨어 내려받기** 버튼 (코드 단계)
- **CSV 저장**: 시뮬레이터·실제 보드 기록을 1초 간격으로 저장 (최대 10시간)

## 실제 보드 연결 사용법
1. ESP32에 v3 펌웨어를 올리고 USB로 PC에 연결합니다.
2. Arduino IDE 시리얼 모니터를 닫습니다 (포트를 한 프로그램만 쓸 수 있음).
3. 데스크톱 Chrome 또는 Edge에서 사이트를 열고 '실험' 단계에서 **연결**을 누른 뒤 포트를 고릅니다.
4. 끝나면 **연결 끊기**를 누르면 시뮬레이터로 돌아갑니다.

## GitHub에 올리기 (업데이트)
1. 저장소 페이지에서 **Add file → Upload files**를 누릅니다.
2. 이 폴더의 파일과 `firmware` 폴더를 통째로 끌어다 놓고 **Commit changes**를 누릅니다.
3. Vercel이 자동으로 다시 배포합니다 (1분 정도).
