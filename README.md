# ESP32 BMS Lab

배터리 없이 USB 5V와 키트 부품으로 만든 ESP32 BMS의 3D 가상 실습실입니다.
한국어 · English · 日本語 · 中文을 지원합니다.

배포 주소: https://esp32-bms-lab3d.vercel.app

## 파일
- `index.html` : 화면 구조와 디자인
- `i18n.js` : 4개 언어 번역
- `lab.js` : 3D 회로, 가상 BMS 시뮬레이터, 조립 단계, 실제 보드 연결(Web Serial)
- `sensors.html` · `sensors.js` : 센서 키트 40종 가상 실습실 (화면·시뮬레이션 엔진)
- `sensors-data.js` : 40종 모듈 정의 — 핀(Uno·ESP32), 가상 신호 모델, BMS 판정 규칙, 예제 코드
- `sandbox.html` · `sandbox.js` : 가상 실험실 — 센서를 꽂고 빼며 회로를 자동으로 만들고 여러 센서를 동시에 시뮬레이션
- `sensors-draw.js` : 모듈 그림 (두 페이지 공용) · `kit.css` : 두 페이지 공용 스타일
- `sensors-circuit.js` : 40종 예시 ESP32 회로 — 브레드보드 배치, 점퍼선·저항, 조립 단계 (3D 실습실과 같은 구멍 좌표)
- `firmware/ESP32_BMS_TFT_v3.zip` : 코드 단계에서 내려받는 펌웨어
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` : 탭·홈 화면 아이콘
- `og.png` : 링크 공유 미리보기 이미지 (1200×630)

빌드 과정이 없는 정적 사이트입니다. 폴더 구조 그대로 올리면 됩니다.

## v5에서 바뀐 점
- 버튼에 포커스가 있을 때 Space를 누르면 부하가 같이 켜지던 버그 수정
- 겹친 카드에 가리지 않도록 3D 화면 중심과 거리를 자동 조정, 키 낮은 화면에서 카드 축소, 카드 숨기기 버튼
- 파비콘과 공유 미리보기 이미지 추가
- 추세 그래프가 처음부터 화면 폭을 채우도록 개선 (SIM/LIVE 표시)
- 시리얼 모니터 맨 위에 열 이름 줄, SOC 열 설명
- 점검 체크리스트 상태를 브라우저에 저장
- 뜨거운 물 실험에서 45°C 전에 위험이 뜨는 이유 설명
- **실제 보드 연결**: 데스크톱 Chrome·Edge에서 ESP32를 USB로 연결하면 펌웨어의 DATA 줄로 화면이 움직임. 부하·리셋 버튼은 on/off/reset 명령을 보냄
- **펌웨어 내려받기** 버튼 (코드 단계)
- **CSV 저장**: 시뮬레이터·실제 보드 기록을 1초 간격으로 저장 (최대 10시간)

## v6: 센서 키트 40종 가상 실습실 (`sensors.html`)
상단 **보기 → 센서 40종**에서 엽니다. 빵빵한 아두이노 센서 키트 매뉴얼의 1~40번 모듈을 모두 다룹니다.
- **가상 데이터**: 거리·온도·자석·불꽃·소리 등을 슬라이더·버튼으로 바꾸면 모듈 전압 → ADC 값 → 예제 코드 계산 순서로 값이 만들어짐
- **자동 시나리오**: 손으로 쥐기 → 뜨거운 물, 팬 멈춤, 불꽃 접근처럼 상황을 자동 재현 (출력 모듈은 예제 코드의 데모 동작)
- **잡음·고장 주입**: 잡음 0~100%, 단선·단락·잡음 폭증·값 멈춤 / **ADC 필터**: 이동평균 10, EMA α0.2 (BMS 펌웨어와 같은 방법)
- **BMS 판정**: 센서마다 주의·경고·위험 기준(수정 가능)과 위험 시 가상 릴레이 차단·래치·리셋. DS18B20은 펌웨어와 같은 32/38/45°C, 상승률, 45°C 도달 예측
- **보드 전환**: Uno(키트 매뉴얼 핀) ↔ ESP32(BMS 보드가 안 쓰는 GPIO36·39·32·21·22·5)
- **예제 코드**: 40종 × 2보드 = 80개, 시리얼 플로터 형식(`이름:값`)으로 출력. `.ino` 내려받기·복사
- **실제 보드 연결**: 예제 코드를 올린 보드를 Web Serial로 연결하면 같은 그래프·판정에 실측값 표시. 출력 모듈은 조작부가 보드로 명령을 보냄
- **CSV**: 실험 기록 저장, **가상 데이터 10분 바로 만들기** (자동 시나리오로 즉시 생성)
- 주소 뒤에 `#번호`를 붙이면 해당 센서로 바로 열림 (예: `sensors.html#27` = 불꽃 감지)

## v7: 40종 예시 ESP32 회로 · 조립 따라하기
센서 40종 페이지의 **🔧 조립 따라하기** 모드에서 센서마다 ESP32 예시 회로를 한 단계씩 만듭니다.
- **BMS 보드와 같은 배치**: 브레드보드 2장 + 가운데 ESP32 (USB 오른쪽), 구멍 이름도 3D 실습실과 같음 (예: `아래 보드 A17 = VP·GPIO36 줄`)
- **BMS 보드에 그대로 추가 가능**: 모듈은 BMS 부품이 없는 위 보드 E44 근처, BMS가 쓰지 않는 GPIO36·39·32·21·22·5만 사용 (DS18B20은 BMS와 같은 GPIO4 버스)
- **단계**: 준비물 → 전원 레일 → 모듈 꽂기 → 모듈 전원 → 신호선 하나씩 → 점검 체크리스트 → 코드 → 가상 실험
- **필요한 저항 자동 포함**: HC-SR04 Echo 10kΩ/10kΩ 분배(5V → 2.5V), LED 모듈 색마다 220Ω
- **그림 조작**: 선·부품을 누르면 그 단계로 이동, 마우스를 올리면 구멍 이름, ←/→ 로 단계 이동, 진행·체크 상태 저장(목록에 ✓)
- **가상 실험에서 회로로 보기**: 같은 회로 위에 HIGH인 신호선이 빛나고 ESP32 쪽 끝에 전압·값 표시
- 40종 모두 전원 단락 없음, 신호가 정해진 ESP32 핀에 연결, 5V가 GPIO에 직접 닿지 않음, 한 구멍에 두 부품 없음을 자동 검사함

## v8: 가상 실험실 (`sandbox.html`)
상단 **보기 → 가상 실험실**. 센서를 하나씩 꽂고 빼면서 ESP32 회로를 만들고, 꽂힌 센서 전부를 가상 데이터로 동시에 실험합니다.
- **＋ / −** 로 40종 중 원하는 센서를 꽂고 뺌 (예시 세트: 화재 감시 BMS, 문·충격 감시, 환경 감시, 입력 장치)
- **ESP32 핀 자동 배정**: 아날로그 → ADC1(36·39·34·35·32·33), 출력·풀업·1-Wire → 입출력 핀(34~39 제외), 가능하면 센서 40종 예제와 같은 핀. 핀이 모자라면 이유를 알려 줌
- **브레드보드 자리 자동 배정**: 3.3V 센서 → 위 보드(3V3 레일), 5V 센서·출력 모듈 → 아래 보드(5V 레일). Echo 분배기·LED 저항 자동 포함
- **BMS 보드 핀 피하기**: 켜면 BMS가 쓰는 14개 핀을 비워 둠 (DS18B20은 같은 GPIO4 버스 공유)
- **동시 시뮬레이션**: 센서마다 자동 시나리오·조작·고장 주입, 공통 잡음·ADC 필터
- **통합 판정**: 센서별 판정 중 가장 나쁜 단계 → 위험이면 TRIP(래치). 릴레이·RGB/듀얼 LED·부저는 통합 판정을 따라 자동으로 동작 (끄면 직접 조절)
- **핀 배치표·배선표·준비물**을 자동으로 만들어 줌, 회로 위 신호선은 HIGH일 때 빛나고 선택한 센서는 값 표시
- **CSV**: 모든 센서를 1초 간격 한 줄로 저장 (`s27_ao` 처럼 센서 번호가 붙은 열), **10분 바로 만들기**는 위험이 사라지고 10초 뒤 TRIP을 자동 리셋하는 가상 운전자 포함
- 주소 공유: `sandbox.html#4,27,20` 처럼 센서 번호를 붙이면 그 구성으로 열림
- 40종 모두 꽂아 보며 전원 단락·구멍 겹침·신호 섞임·5V가 GPIO에 닿는지 자동 검사함

## 실제 보드 연결 사용법
1. ESP32에 v3 펌웨어를 올리고 USB로 PC에 연결합니다.
2. Arduino IDE 시리얼 모니터를 닫습니다 (포트를 한 프로그램만 쓸 수 있음).
3. 데스크톱 Chrome 또는 Edge에서 사이트를 열고 '실험' 단계에서 **연결**을 누른 뒤 포트를 고릅니다.
4. 끝나면 **연결 끊기**를 누르면 시뮬레이터로 돌아갑니다.
