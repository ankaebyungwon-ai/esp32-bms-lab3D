# RE:CELL 14 — 폐배터리 활용방안 (리모델링 첫 화면)

폐배터리 활용방안을 정리한 학생 연구 사이트 **RE:CELL 14**의 새 첫 화면입니다.
아이소메트릭 3D UI와 밝은 색으로 다시 만들었고, ESP32 BMS 3D 회로와 새 주제 6개를 넣었습니다.

- 기존 사이트: https://battery-recycling-xi.vercel.app/
- 3D 조립 실습실: https://esp32-bms-lab3d.vercel.app/

![주제 화면](assets/preview-topics.png)

## 구성

```
index.html                 첫 화면 한 장 (HTML·CSS·JS 모두 이 파일 안에 있음)
docs/references-new.md     새 주제 6개 요약과 추가 참고자료 23건 목록
assets/                    README용 미리보기 이미지
```

빌드 과정이 없는 정적 페이지입니다. 외부에서 불러오는 것은 두 가지뿐입니다.

- Google Fonts (Noto Sans KR, Space Grotesk)
- three.js 0.170.0 (jsDelivr CDN) — BMS 3D 회로용. 불러오지 못하면 3D 대신 실습실 링크가 나옵니다.

### 출처 원칙

- 논문은 DOI로 확인하고, PubMed에 있으면 PMID를 함께 적었습니다.
- 법·제도는 정부(산업통상부, 환경부, 국가기술표준원), 국회, EU(EUR-Lex), 국제기구(UN, ICAO, IEA) 원문을 우선했습니다.
- 법무법인·산업 단체 자료는 ‘해설’로 표시했습니다.
- 기존 01–14번 주제와 85편 참고문헌은 기존 사이트 페이지로 연결됩니다.

## 링크 방식

01–14번 주제, 소개·해부도·참고문헌 등 하위 페이지는 **기존 사이트 주소(절대 경로)** 로 연결됩니다.
그래서 이 저장소를 새 Vercel 프로젝트로 배포해도 기존 하위 페이지가 그대로 열립니다.

> 기존 Vercel 프로젝트(battery-recycling-xi)를 이 저장소로 **덮어쓰면** 기존 하위 페이지가 사라질 수 있습니다.
> 새 프로젝트로 배포하거나, 기존 프로젝트의 원본 소스에 `index.html`만 바꿔 넣으세요.

## GitHub에 올리기

1. GitHub에서 저장소를 만들거나 기존 빈 저장소를 엽니다.
2. **Add file → Upload files** 에서 이 폴더 안의 파일을 모두 끌어다 놓고 **Commit changes** 를 누릅니다.
   (명령어를 쓴다면 아래처럼 올립니다.)

```bash
git init
git add .
git commit -m "RE:CELL 14 첫 화면 리모델링 + 새 주제 6개"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

3. Vercel에서 **Add New → Project → 이 저장소 Import → Deploy** (Framework: Other, 빌드 설정 없음).
